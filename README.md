# Fantasy Football Pipeline

Fantasy Football Pipeline is a personal, non-commercial project for analyzing my own fantasy football leagues.

The project pulls read-only league data from fantasy platforms and organizes it for personal analysis, including:

- League settings
- Team rosters
- Current lineups
- Matchups and scores
- Standings
- Transactions
- Waiver and free-agent data
- Player information

The goal is to use this data to support personal fantasy football decisions such as:

- Lineup optimization
- Waiver-wire evaluation
- Trade analysis
- Roster management
- Weekly matchup strategy
- Short-term player value tracking

This project is intended for my own use only. It is not a public or commercial service and is not distributed to other users.

## Yahoo Fantasy Sports API

Yahoo Fantasy Sports API access is used only for read-only analysis of my own Yahoo Fantasy Football account and leagues.

No Yahoo credentials, access tokens, refresh tokens, client secrets, or other private authentication data are stored in this public repository.
